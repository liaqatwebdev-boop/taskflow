# To-Do List App

A modern, responsive To-Do List App built with HTML, CSS, and JavaScript. This project helps users organize daily tasks through a clean interface and simple interactions.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Clean and user-friendly interface
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks.
